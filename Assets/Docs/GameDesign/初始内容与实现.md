# TAPTAP 

1. 基础设计

游戏玩法为2D平台类游戏，核心玩法模块为控制角色上下身分离与合并这一基础规则，与地形和其它机制产生各式各样的交互规则产生的玩法机制涌现形式。游戏中场景构建以单位格为基准。单位长度是一个可定义的数字，适配美术最终设定的单格长。目前阶段，1单位长度 = 游戏世界距离的1.



2. 基础操控

游戏仅提供三个键位操作：左，右，空格

角色形态：高度约1.7长度，其中上/下半身均为约0.8单位长度，中间保留较小空间。

左右控制角色的移动，空格控制玩家的头身分离操作。





3. 基本地形与头身分离操作规则

当玩家头身在一起时

[按住空格]——将头部向上弹出至多4.4个单位高度（缓出曲线），并使用一根磁力线条连接，长按期间，脑袋会跟随人物移动。

[松开空格]——头部首先向下缩回（缓入曲线），根据路径上触碰到的物体，产生不同的后续交互。

游戏中最常见的两类物体：普通墙体和单向平台

1） 当头部上升时，触碰到单向平台：头部正常从下往上穿过平台

2） 当头部上升时，触碰到墙体：头部停止上升并悬停在当前高度，即使之后移动使头部上方不再有平台，也不会继续升高。

3） 当头部下降时，触碰到单向平台/墙体：头部停止下降并停留在平台/墙体上，随后将下方的身体向上吸附（缓入曲线）。

​	如果身体在上升过程中触碰到了墙体，则结束吸附，并且使头身分离。

​	如果身体成功接触到了头部，则会重新连接，并在接上时额外提供一个1格左右的向上速度以保证能跳跃上平台。



当玩家头身分离时

此时头部留在原地，只有下身可以进行移动。

[按住空格]——淡入一条引导线，从头部向下方无限距离延伸，当角色在头部接近正下方的区域时色彩淡入为蓝，否则淡入为红。

[松开空格]——若玩家下身此时在头部正下方（无论多远），吸附玩家。若不在，则引导线红着额外显示一小会后淡出。每次进行这个尝试在一个短暂的CD后才能再次按空格，期间按下的空格将缓存为最多一次的预输入，避免狂按导致可能的BUG。

若吸附成功：

1）玩家初始若在头部下方5单位长度以内，则玩家执行如同正常收头时的吸附操作

2）若玩家初始在头部下方5单位长度更远的地方，则玩家在吸附上头部时会额外跃起1格（想象一个强大的冲击力）



散落的头部还有可能与玩家有其它交互

1）若头部从上方落到玩家身上（例如传送带），玩家会身体（y轴变小x轴放大地）放缩表现出向下冲击力并重新超级拼装。此时若玩家站在单向平台上，那么会被砸下去。（如同传统2D平台游戏中，在单向平台上按↓那般）

2）若身体走到头部上，它会把头部当成一个弹簧并向上弹起3格。（任意可运动实体在触碰到头部后都会向上弹起3格）



4. 其它机制

主要用于辅助探索头身分离的可挖掘机制的系统。

1） 传送带，玩家，头，以及任意其它可运动实体，在开启的传送带上都会被朝着其运动方向推进。

2） 虚化/实化平台，游戏中有按钮开关，

3） 复活点，知识锁机制。复活点即玩家在当前关卡的出生点，目前以一面小旗帜作为标识，当玩家以任意形式死亡时，若此时玩家头身在一起，那么玩家会播放死亡特效并变为拖尾飞回复活点。若玩家头身已分离，则玩家的身体播放死亡特效飞回复活点，头部不变。复活的本质是将当前操控的单位传送回复活点，不会重置场景。当玩家跨场景时，可以通过触碰那个场景复活点旗帜的方式来修改自己的复活点。

5. 特效

特效应当继承一个懒汉单例基类，用于承载一些基础常用特效的直接调用。

相机应当有一个额外的专用于运动处理的根物体，震动等特效全部作用于它上面。

玩家本体视觉部分的scale的放缩，可以从EffectManager路由到对应实体上。

对于当前的系统，以下行为进行特效：

1. 头部下落到地面/平台时，玩家上升并撞到地形时，短暂震屏。
2. 玩家头身结合时，轻微相机放大 + 轻微时缓 + 玩家视觉形象放缩
