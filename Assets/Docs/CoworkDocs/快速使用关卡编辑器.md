# 关卡编辑器

此编辑器用于快速搭建谜题、生成关卡，并配置各关卡的固定透视镜头。

快速探索一些谜题组合的难度和心流曲线，以及预览它们的地形结构，方便后续挑选放进大地图组合。



### 怎么用？

1. 在上方菜单点击 **TapTap → Level Designer** 打开关卡编辑器

![image-20261006221036071](figs/image-20261006221036071.png)

2. 新建一个关卡配置，文件的保存位置预设好了，只需要给它命名即可

![image-20261006221601566](figs/image-20261006221601566.png)

3. 在编辑器中直接设计关卡，左键涂鸦，右键橡皮，中键取色，其它功能和像素绘画软件差不多。

调整画布时，直接拖动画布外侧的蓝色边缘或箭头把手：向外拖动扩展，向内拖动回缩，四条边均支持。拖动时显示扩展或回缩的格数，松开确认，Esc 取消；每个方向最小保留 1 格，最大 2048 格。侧栏“画布边缘”提供四个扩展按钮，每次可选增加 1、4、8、16 格。调整只改变可编辑范围，原有图块、入口、批注和大世界中的位置保持不动，Ctrl+Z 可撤销，Ctrl+Y 可重做。回缩后越界的图块仍然保留，暂时隐藏并提示越界；重新扩展或撤销后恢复显示。越界图块需重新纳入画布或主动删除后才能保存 Prefab，回缩不会自动删除。向左或向下扩展后，新区域允许使用负坐标。上方宽高输入继续保留，增加宽度向右扩展，增加高度向上扩展。画布与按图块自动生成的实际关卡轮廓分别调整，调整画布不会改写手动边界。

![image-20261006221219391](figs/image-20261006221219391.png)

4. 选择一键生成测试场景，会自动将需要配置的其它内容完成并创建该场景，Play即可直接测试效果

![image-20261006221728748](figs/image-20261006221728748.png)

5. 保存的关卡预览位置

### 配置固定透视镜头

关卡编辑器侧栏、关卡 SO 的 Inspector，以及场景 `LevelRegion` 的 Inspector 均提供“固定透视镜头（关卡共享）”面板。镜头保存在关卡 SO 的 `CameraSettings` 中，测试场景和大地图通过 `LevelRegion.Source` 读取同一份配置，修改镜头后不需要重新生成地图 Prefab。

1. 打开对应测试场景，或在大地图中选中该关的 `LevelRegion`，确认面板的“场景参照”指向该实例。
2. 点击“生成默认镜头”可按当前关卡范围生成固定正视镜头；也可以将 Scene 视图切为透视、调整取景后点击“采集 Scene 视图”，或调整一个透视 Camera 后选中它并点击“采集选中相机”。采集会同时记录位姿与镜头参数。
3. “位置（格）”相对该区域原点，随区域位置、旋转和单位缩放转换到世界空间；“局部旋转”也是相对区域的旋转。默认模式调节垂直 FOV；切换为 Physical 模式后使用毫米焦距，并一同保存传感器尺寸、镜头偏移与画幅适配。每关可使用不同焦距。
4. 点击“预览本关镜头”查看真实场景渲染，可选择 16:10、16:9、4:3 画幅；预览使用临时相机，保持场景主相机不动。完成后点击“保存镜头”。预览仅用于非 Play 状态。

运行时每关使用固定镜头，不跟随玩家。身体进入另一关时，从当前画面位置、旋转及镜头参数平滑过渡；目标关的“进入过渡（秒）”与“过渡曲线”决定效果，时长为 0 时立即切换。首次进入、黑屏跳转与回溯切区直接还原目标镜头，暂停时冻结过渡。尚无预设的旧关卡会自动按完整区域范围取景。

地图暂时采用直接显隐：未发现区域关闭各类 Renderer 的绘制，并暂时关闭区域下的 Unity Light，进入后恢复隐藏前的灯光开关状态，保留原材质、碰撞和机关逻辑。未来可通过 `RegionRevealView.ApplyVisibility` 替换表现；运行中向区域添加新外观或灯光后调用 `RefreshVisuals()`，让新对象继承当前可见状态。

测试场景与大地图游玩场景目前统一使用 Color 环境补光，RGB 默认均为 0.4，配合原有方向光，让背光面保留细节。可在 **Window → Rendering → Lighting → Environment → Environment Lighting** 调整 Source 与 Ambient Color；这些是场景配置，不属于关卡镜头 SO。新生成的测试／大地图游玩场景会使用此默认值，正常同步已有大地图会保留其手动光照设置。

### 批量框选与移动

按 **V** 或选择“框选 / 移动”工具，按住左键拖动框选矩形区域。在选区内按住左键拖动，预览目标位置，松开后完成批量移动；也可以用方向键逐格微调。按 **Shift + 左键拖动** 可重新框选，拖动途中按 **Esc** 取消移动。

移动会用整个选区覆盖目标区域，选区中的空格也会清空对应目标格；原位置空出的部分留空。选区与目标重叠时也按这一规则处理。默认移动所有图层，开启“仅显示当前图层”时只移动和覆盖当前图层。选区不能移出地图边界；一次移动可用 **Ctrl+Z** 撤销。选中物体的配置、批注和入口标记随物体保留；若覆盖了未选中的入口复活点，需重新指定入口。

### 整张地图镜像

侧栏顶部“快速镜像”提供 **左右镜像** 和 **上下镜像**，以当前编辑画布的中线翻转整张地图。操作包含全部图层，即使开启“仅显示当前图层”也会一起镜像；图块、批注、入口、框选区域及已有手动边界一起换位，画布尺寸和大地图中的模块原点保持不动。尖刺朝向、左右传送带方向与复活点出生偏移会相应翻转，批注文字保持原文。大地图预览即时更新，Ctrl+Z 撤销，Ctrl+Y 重做。Prefab 中手动添加的 Custom 对象不属于网格内容，保持原样；更新测试场景需重新生成。

### 物体转向

按 **T** 或点击侧栏的“转向 [T]”按钮：在笔刷、矩形或油漆桶工具中转向当前笔刷；按 **V** 选择已放置的物体后，转向选中的物体。框选区域时，各个支持转向的物体会分别转向，格子位置不变；不支持的物体跳过。已放置物体的转向支持 Ctrl+Z 撤销。

- 尖刺每次顺时针转 90°：上 → 右 → 下 → 左。外观和致死碰撞体一起旋转，也可在“朝向”下拉框中直接选择。
- 传送带每次切换左右方向（箭头转 180°），同时反转速度正负；停止的传送带也能切换箭头方向。
- 机关按钮每次切换上下方向（转 180°），也可在“朝向”下拉框选择上或下。向上的按钮贴格子底边，向下的按钮贴格子顶边，外观与触发碰撞体一起翻转。上下镜像会同步反转按钮朝向，左右镜像保持上下朝向。

转向会显示在网格预览中，并保留在关卡资源、复制粘贴和生成的 Prefab／测试场景里。**R** 仍然是矩形工具。

### 指示灯光与钥匙阶段

区域编辑器新增“指示灯光”笔刷，位于独立的 `lights` 图层。灯光为无碰撞的梯形渐变条带，以短边中心为原点，默认向下展开。每个灯光默认游戏开始时关闭，可单独勾选开局打开；短边选择 2／3 格，长边、长度、颜色透明度、渐变强度和旋转角度可独立设置。编辑时始终显示渐变预览；游戏中灯光绘制在地形上方、角色下方。T 顺时针旋转 90°，也可输入任意角度。复制、镜像及保存会保留配置；修改后通过 **TapTap → 保存并同步大地图** 手动同步。

也可以直接将 `Assets/Prefabs/Interactables/Grid/GridIndicatorLight.prefab` 拖入场景，在 Inspector 设置并使用旋转工具。手动放置时 `Grid Unit` 指定每格的世界尺寸；灯光笔刷使用关卡单位缩放，保留该字段为 1。若需要受区域显隐控制，请放到对应 `LevelRegion/Custom` 下。

将 `Assets/Prefabs/Interactables/ProgressKey.prefab` 手动放到对应区域的 `Custom` 下，通常只放一个。钥匙不自动添加到现有地图。身体接触钥匙会触发一次镜头放大再还原的 DOTween 动画与时缓；头部不能单独拾取。动画期间暂时锁定操作、回溯和重置，暂停物理模拟以避免死亡。动画使用真实时间，钥匙 Inspector 可调整放大幅度、放大／停留／还原时长和时缓比例。

动画结束后进入下一阶段：所有出口失效、场景所有灯光打开，清空旧 Z 回溯历史并从此刻重新记录。之后按 R 重置或重新加载此游玩场景，仍处于下一阶段：钥匙已拾取、灯光全开、出口关闭；区域发现记录依原规则重置。阶段只保留在本次 Play 运行中，下次重新进入 Play 才恢复初始配置。O 继续按原有规则切换出口，无优先级锁定。

灯光统一订阅 `EventManager` 的 `LightsStateRequested`，由 `EventManager.Publish(new LightsStateRequested(scene, true/false))` 指定场景所有灯光的状态；重复发送不会反转状态。打开灯光不会揭示未探索的区域。

### 测试批注与体验评价

使用“测试批注 [N]”笔刷放置批注，在关卡编辑器中将鼠标放到批注上按 N 编辑原文。批注原始内容保存在 `Assets/Runtime/Levels/*.asset` 中的 `Placements → AnnotationPlacementSettings.Text`；测试场景里的批注只是它的展示实例。

在 Unity 编辑器的 Play 模式测试场景时，角色身体或头部靠近红色批注标记，会出现批注内容和 E 键提示。按 E 打开 UGUI 评价窗口，只需给“感觉如何”选一个 1～5 分，补充说明可写可不写。多个批注范围重叠时打开距离角色最近的一个。

窗口打开期间暂停游戏，输入文字不会触发移动、头身分离或 R 键重置。点击分数立即保存，补充说明输入停顿半秒或失去焦点后自动保存，点击“继续玩”、按 Esc 或退出 Play 模式时也会保存。评价带时间追加到原始批注末尾，保留原文和此前的评价；同一次窗口内继续修改会更新当前记录。退出 Play 模式后可在关卡编辑器按 N 查看和编辑这些评价。

新生成的测试场景通过批注 ID 定位原始内容；旧测试场景自动通过所属关卡和批注的格子位置定位。若窗口提示找不到原始批注，请重新生成测试场景。回写功能用于 Unity 编辑器的 Play 模式，发布后的游戏不写入工程资源。

### 大地图模板与拼装

打开 **TapTap → World Map Designer**，会继续打开上次使用的布局。双击 `Assets/Runtime/WorldMaps/World_Character.asset` 可直接打开角色模板。也可点击“新建地图”，保存独立的拼装方案，再从侧栏选择“分体角色”或“爱心”模板。切换模板会采用该形状的默认尺寸，保留全部模块位置，可撤销。

大地图的一格对应单关的一格。侧栏可分别设置模板宽度和高度，或选择比例一致的小、中、大尺寸。“显示参考底图”可开关模板；模板与外围留边只作视觉参考，不限制放置位置。调整模板尺寸或留边保留所有模块坐标，不会缩放关卡或自动挪动模块。

**分体角色模板**由上下等高的两个主体组成：顶底保持直线，四角圆角，中间相向的边缘略微外凸，上下之间留一条窄缝。轮廓采用之前确认的主体造型，不包含天线、手脚和表情。默认总尺寸为 320×448 格，小号为 160×224，大号为 640×896；总尺寸包含两侧外凸边缘和中缝。中缝默认占总高约 2.2%（默认尺寸留空 10 格），圆角半径默认占主体宽度的 5.5%，都可以在侧栏调整。中缝取完整格子，并保证上下等高，实际格数会显示在侧栏。中缝显示为灰色参考区，允许关卡横跨中缝或摆到模板外侧。

**爱心模板**继续保留在 `Assets/Runtime/WorldMaps/World_Heart.asset`，已有布局的尺寸、模块引用和位置沿用原数据。爱心左右对称，以直边、斜边构成主体，在顶部心瓣和两侧肩部使用少量曲线连接。小、中、大尺寸分别为 160×144、320×288、640×576。

从模块库选择“放置”，再点击画布确定该关卡的原点（原始编辑画布的左下角）。也可以从 Project 拖入关卡布局 `.asset` 或带有来源布局的区域 Prefab。拖动模块内部可整体移动，方向键逐格微调，Shift+方向键移动 8 格；侧栏可精确输入原点坐标。滚轮以鼠标所在位置缩放，中键或 Alt+左键平移，按 F 查看全图。

**框选并整体移动**：在“拼装 [V]”模式下，从空白处按住左键拖出选框；按住 Shift 从任意位置拖动可重新框选。选框碰到实际关卡范围就选中整个模块，L/S 形关卡的空缺不会误选。多个模块会一起高亮，并显示整体选区；拖动任意所选模块或选区内空白，可以整组移动并保持相对位置。松开确认，Esc 取消，Ctrl+Z 撤销；方向键整体移动 1 格，Shift+方向键移动 8 格。Ctrl+D 和 Delete 对整组选中的模块执行复制和删除。多选时暂不显示单个关卡的边界调整把手，单选后可继续调整；通行箭头仍单独移动。“框选新关卡 [B]”继续用于创建等大的子关卡。

**双击模块直接打开该关卡的网格编辑器**，与侧栏“编辑单关”的行为一致。若要查看场景，点击侧栏“打开场景并定位关卡”。已生成的测试场景会按来源关卡自动匹配，也可在侧栏的“导航场景”指定场景；绑定使用 GUID，场景改名或移动后仍有效。没有对应场景时，首次场景导航会生成测试场景，之后重复打开该场景。导航到含有整体大地图 Prefab 的场景时，会优先按生成物体名称中的模块 ID 定位所点击的那一份关卡。切换场景前 Unity 会按常规提示处理未保存的场景。

拼图以**最外层图格形成的实际关卡轮廓**为单位，可呈 L、S 或其他不规则形状，并保留凹口和独立块。图格围住的空白内部也属于关卡范围，与外侧相通的凹口留空。测试批注不扩大范围，尚未放置地形的关卡暂用原始画布范围。允许模块跨模板轮廓、中缝及负坐标摆放，不再提示模板越界或因此阻止生成；按 F 和导出 PNG 都覆盖实际模块范围，底图开关也会反映到导出结果。

**重叠图块检查**：同一格的图块 Prefab、图层、定位偏移和机制配置必须一致，双方都为空格也视为一致。尖刺朝向、传送带速度或方向、虚实状态等配置不同，同样视为冲突；测试批注不参与比较。大地图面板会用橙色标出具体冲突格，侧栏显示冲突模块与坐标；编辑、拖动、撤销和 Inspector 修改后刷新。实际场景的检查仅在 **TapTap → 保存并同步大地图** 更新地图时执行，包括场景中单独修改的朝向、碰撞和机制配置。Scene 视图的橙色框显示上次同步的检查结果，不再定时扫描，也不会在重绘时重新扫描。生成整体 Prefab 前仍须解决图块冲突、来源缺失及单位长度不一致等问题。粉色轮廓仅作为底图参考。
**选中模块后，拖动白色轮廓或方形把手可逐格调整那一段边界。** 拖动时预览，松开提交，Esc 或窗口失焦取消；Ctrl+Z 撤销。只修改关卡范围，不挪动、缩放或删除地形，向内拖动也会保留已有图块所在的格子。手动范围可以超过原始编辑画布，地形仍保持原始局部坐标；若要在扩展范围内绘制新地形，需在单关编辑器另行扩大画布。侧栏“恢复按图格自动生成边界”可恢复自动轮廓。边界保存在来源关卡里，同一来源的所有模块一起更新；关卡编辑器用绿色线显示实际轮廓，场景中的 LevelRegion Gizmo 也显示这一轮廓。相机按轮廓的外接矩形限制跟随范围；凹口、独立块之间的留空和地图外侧暂时正常显示，不加遮罩。

**关卡相机设置**：选中来源关卡布局 `.asset`，在 Inspector 的 `Camera Settings` 中默认启用 `Auto Size`：镜头 Size 取地图外接矩形长宽较大值的一半，上限 12 格；不超过 12 时固定居中，超过 12 时以 Size 12 平滑跟随。关闭 `Auto Size` 后可手动设置 `View Size`（镜头半高，默认 9 格）。还可配置 `Follow Horizontal` / `Follow Vertical`（横纵跟随开关）、`Offset`（相对身体表现位置的偏移）和 `Dead Zone`（缓冲区半宽、半高占整个画面的比例，默认中央 20% 宽、30% 高）。没有来源布局的区域可直接在 `LevelRegion` 中配置。玩家超出缓冲区才会带动镜头，普通小幅移动和跳跃保持画面稳定；宽高不足一屏的方向居中显示，长关卡仍可在另一方向跟随。设置跟随来源关卡保存，重新生成 Prefab 时保留；已有测试场景无需重新生成，运行时会按新设置跟随。启用跟随时，出生定位会立即对准玩家，回溯直接跟随当前历史位置；固定镜头始终保持地图居中。

关闭“显示内部地形”可专注查看关卡块的整体形状；开启时显示原始布局里的墙体、平台、机关和标记。当前预览按布局数据绘制，不包含区域 Prefab 的 `Custom` 下手工添加的美术。模块使用原始关卡引用；编辑单关会更新引用该关卡的所有模块。如需制作变体，先复制单关资源。

Ctrl+D 复制选中模块，Delete 删除，Ctrl+Z / Ctrl+Y 撤销和重做，Ctrl+S 保存大地图布局及引用关卡的边界修改。导出 PNG 可获得整张地图的像素预览，开启参考底图时同时导出模板，关闭时只导出地图内容；模板外和负坐标的模块不会被裁掉。

“生成整体 Prefab”按网格坐标将全部模块放在同一个根物体下，默认保存到 `Assets/Prefabs/WorldMaps`。单关保持嵌套 Prefab 引用，单关和大地图的 `Custom` 内容在重新生成时保留。该按钮会根据当前布局更新所使用的单关 Prefab。将整体 Prefab 放入同一个场景即可查看空间拼装结果；添加配置好的 GameplayRuntime 和玩家后可运行关卡流程，也可以直接使用“生成入口与游玩”。模板灰区和粉色轮廓仅用于编辑和 PNG 预览，不会生成游戏碰撞体。

### 通行标记与框选新关卡

大地图侧栏顶部有三个设计工具：**拼装 [V]、通行 [P]、框选 [B]**。

选择“通行”，在画布上点击放置一个独立的黄色箭头。在侧栏用方向按钮或角度滑条调整朝向，可填写备注，并选择是否“双向通行”（显示双头箭头）。箭头直接放在需要指示穿行的位置。

点击已有箭头可选中，拖动或用方向键移动；侧栏可以精确改坐标、复制、删除。地图平时只显示箭头，选中后显示备注，悬停可查看备注。通行标记保存在大地图布局中，支持保存、撤销和重做；PNG 导出也使用独立箭头，完整文字备注保存在布局中。标记用于宏观通行设计，游戏里的实际跨关行为仍由运行时逻辑实现。

选择“框选”，在画布上按左键拖出矩形区域，快捷指定新关卡的画布大小和位置。区域包含起点和终点格，正向、反向拖动都可以；松开后，侧栏显示左下角坐标和宽高，可继续精确调整。**创建时不检查与已有关卡是否重叠**，可以直接在已有模块上框选。绿色表示可创建，红色提示范围进入模板灰区。

检查大小并选择物体配置后，点击**“确定创建子关卡并进入编辑器”**，输入新关卡名称。新建布局的画布宽高与框选范围完全相同，自动放到该范围左下角，并打开单关编辑器。创建的是普通关卡，不预设手动边界；开始绘制后，实际轮廓按最外层图格自动生成，编辑画布仍保持创建时的尺寸。选择已有资源名称时会生成新路径，保留原资源。Esc 取消框选；创建后 Ctrl+Z 可撤销地图中的放置，新关卡资源仍保留在模块库中。

单关编辑器里的绘制、擦除、移动和物体配置修改会主动刷新大地图地形和轮廓，**无需保存或切回大地图**；同一来源的所有模块同步更新。撤销、重做以及 Inspector 中的布局修改也会刷新预览。更新地形预览不改变模块在大地图中的原点坐标；已经手动设置的边界继续保留。


### 同场景完整游玩流程

在大地图中选中模块，设置“关卡序号”。程序按序号从小到大推进，序号可以不连续，但不能重复；旧地图的 0 沿用列表顺序。“按当前列表重新编号 1…N”可一次编号，新建或复制的模块自动使用末尾的新序号。序号属于大地图中的模块，同一个单关资源的不同摆放可使用不同序号。

游玩场景提前保存完整地图、玩家和相机，编辑状态下显示全部区域，无需进入 Play 即可查看拼装效果。修改大地图或单关内容后，通过 **TapTap → 保存并同步大地图** 手动保存布局、更新单关 Prefab 并保存完整游玩场景；大地图面板的“保存”按钮和面板内 Ctrl+S 执行相同操作。“保存并打开游玩”还会打开对应场景并定位完整地图。编辑、撤销、重做和进入 Play 不再自动触发场景加载、生成或保存。菜单优先使用当前聚焦的大地图面板或选中的大世界资源，其次使用当前场景的大世界、已打开面板及上次使用的布局。

“生成选关入口”也会确保游玩场景包含完整地图，不再创建运行时拼装入口。初始选关场景自动放到构建列表首位。手动同步以模块 ID 复用已有区域实例，保留它们的 `Custom`、场景中额外添加的物体以及玩家的手工摆放；删除模块会移除对应区域。同步在编辑状态下运行，Play 期间不重建地图。未完成或暂时无效的单关编辑会提示并保留上一次有效地形，其他模块仍可正常同步。实际游玩仍需为各单关指定入口复活点、配置终点及一致的网格单位。

运行时所有区域的碰撞与机关持续运行。本次运行中未进入过的区域完全不可见，首次进入以 0.45 秒淡入，之后在本次运行中保持可见，离开和回溯不会重新隐藏。发现状态不写入存档；重置整个世界或重新进入游玩场景后，仅当前入口区域立即可见，其他区域全部重新隐藏。发现区域同时解锁选关，但不计入通关，通关和解锁记录独立保留。身体碰撞中心离开当前区域超过默认 0.12 格缓冲后，进入另一块实际轮廓即切区；头部跨区不影响区域选择。相机平滑移动与调整尺寸，已发现的邻区可以入镜。自然跨区不暂停、不传送、不重置机关、不清空回溯。当前区域的入口旗帜直接决定复活点，触碰其他旗帜不再改变它，身体死亡返回途中不切区。边界缓冲可在 `WorldMapProgression` 的 `Region Buffer` 调整。

身体抵达终点后的按序推进仍保留原流程：显示已通过关卡的编号轮廓，恢复世界初始对象与机关状态，将玩家传送到下一关入口，切换复活点与镜头并清空回溯。该流程及 R 重开都会清空本次发现状态，仅新的入口区域可见。轮廓按实际格子边界自动生成，保留凹形和独立区域。

打开关卡编辑器后，物体库会自动补充“方形平台”笔刷。它占据完整一格，编辑器和大地图预览用绿色方块标记，Prefab 外观采用接近普通墙体但有区别的灰色，仍采用平台的单向碰撞规则。Prefab 的 `SquarePlatform` 组件预留 `NotifyHeadPassedUpward` / `NotifyHeadLanded` 通知入口、C# 事件与 Inspector 事件，未来可接入动画，本阶段不自动检测或播放动画。

**平台自动拼接**：普通薄平台与方形平台继续按格绘制，同排相邻的同类平台自动使用左端、中段、右端模型，孤立一格使用独立模型。增删格子后预览立即更新，保存区域 Prefab 或重新生成测试场景后更新场景模型。两类平台分别连接，保持原有二维单向碰撞。模型在各自 Grid Prefab 的 `PlatformTileVisual` 组件中配置 `Single / Left / Middle / Right Model`，可直接替换为 3D Prefab。

**传送带自动拼接与箭头闪光**：同排且速度、朝向和连接组一致的传送带自动使用左端、中段、右端模型，至少连续两格。两格直接拼成左端和右端，没有独立格模型；编辑过程中的孤立格显示橙色框和感叹号，生成前需补齐。同一段传送带可用同一笔刷参数连续绘制；T 或左右镜像会反转速度。原有二维碰撞及实际传送速度保留。

打开 `Assets/Prefabs/Terrain/Grid/GridConveyor.prefab`，在 `ConveyorTileVisual` 配置 `Left / Middle / Right Model`、`Arrow Glow Material`、`Flash Period`（默认 1.5 秒）和 `Flash Duration`（默认 0.6 秒，含渐入和渐出）。模型标准宽度为 1 格，本地 +X 为向右。中段通过视觉父节点的 X 缩放随运动方向翻转，左右端头保持各自的端部角色，碰撞盒不跟随翻转。停止时保留最近朝向，箭头熄灭。

在中段模型的根节点或箭头标志根节点挂 `ConveyorArrowPulse`，将箭头对应的 `Renderer` 与 `Material Index` 填入 `Arrow Materials`。索引从 0 开始，可为同一个网格指定多个箭头材质槽，或绑定多个箭头 Renderer；其他材质槽保持原样。当前 `ConveyorMiddle` 在模型根节点挂组件，绑定 `Arrows` 下两个 `Direction_Chevron` 的材质槽 0，同步渐变发光；旧的 `Arrow >>` 占位模型已停用，预设 HDR 发光颜色为青绿色，峰值强度为 8。该组件节点的世界 X 坐标为 p，向右时相位为 `(0.2 × p) mod T`，向左为 `(-0.2 × p) mod T`，余数统一归到 `[0, T)`；在统一时钟每周期到达该相位时开始渐亮，持续时间的前三分之一平滑渐入、中间三分之一保持峰值、最后三分之一平滑渐出，然后还原最初的材质。颜色与 HDR 发光强度共同插值，运行时使用独立材质实例，不改写共享素材。多个尖括号属于一个 `>>` 标志时可放在同一个组件下同步亮起。时钟使用回溯管理器的模拟时间，未使用管理器时使用 Unity 游戏时间，因此暂停、调试倍速和回溯都跟随游戏进度。默认模型和 HDR 发光材质位于 `SmartModels/Conveyor*`。修改模型或参数后，保存区域 Prefab 并重新生成测试场景以更新既有实例。

**开关活塞**：新增独立笔刷，现有两种虚实方块及其旧关卡数据继续保留。选择活塞笔刷，在空格点击并拖动可确定方向和整数长度；点击固定格块靠近某一面的区域，可将薄基座自动贴到该面，再向外拖出长度。右侧可设置方向、最大伸出长度（1～2048 格）和“开关亮起时伸出”。配置坐标是伸出的第一格，薄基座位于该格背面边界，没有独立碰撞，也不额外占一格；最大长度包含末端；默认使用薄盖模式，长度 1 也有主体和薄盖。兼容旧整格末端模式时，长度 1 只有末端。活塞位于独立的 `pistons` 图层，最大伸出范围不能与地形或平台重叠。

选择工具可点击活塞任意一段选中整个机关，拖动末端黄点逐格调长短，T 每次转向 90°。框选、移动、复制、删除和镜像都处理完整活塞；边界和大地图重叠检查也覆盖最大伸出范围。活塞与按钮共用现有全局开关，碰撞瞬间完整出现或消失，模型随后播放默认 0.18 秒的伸缩动画；回溯时碰撞和模型直接恢复历史状态。`GridPiston.prefab` 的 `PhasePiston` 组件提供基座、中段、末端三个模型槽及动画时长。模型以本地 +X 为伸出方向，每段标准长度为 1；模型作为视觉子物体，可保留自身的导入旋转与缩放。现已配置 `Telescopic_Base`、`Telescopic_Cube`、`Telescopic_Cover` 三维模型，仍采用原有二维碰撞。

活塞素材配置：打开 `Assets/Prefabs/Terrain/Grid/GridPiston.prefab`，在 `PhasePiston` 中将 `Base Model`、`Body Model`、`Tip Model` 分别设为 `SmartModels/TelescopicBase`、`TelescopicBody`、`TelescopicCover`。启用“末端使用薄盖”，默认“薄盖厚度（格）”为 0.12。基座固定在伸出起点后方；薄盖只平移，动画中厚度不变，收回后仍可见并贴在基座上；主体按整数格分段填满基座与薄盖之间的空间。薄盖模型沿本地 +X 标准化为 0～1，厚度参数决定实际显示厚度；主体模型沿 X 以中心为原点、标准长度 1。基座厚度当前为 0.14 格，主体横截面为 0.82 格，盖板横截面为 1 格。FBX 的原始偏移和朝向由包装 Prefab 中的 `Model Fit` / `Model Orientation` 适配，无需修改导入设置。更新 Telescopic 源模型后执行 **TapTap → 美术 → 配置 Telescopic 活塞模型**，会重新适配三个模型并刷新现有关卡活塞外观；方向、长度、虚实关系及碰撞不变，场景沿原 Prefab 引用更新。

按 O 切换所有出口是否生效，再按一次恢复；HUD 显示当前启用或停用状态。停用期间触碰终点不会通关或转场，出口外观与其他机制保持原样。本次游玩中的重开和跳关保留该开关，重新加载游玩场景默认启用；转场、回溯及填写反馈期间不响应 O。

运行时调试倍速默认 1 倍，按 I 按 **1 → 2 → 4 → 8 → 1** 循环，HUD 显示当前倍速。本次游玩中的重开及切换场景保留倍速，重新启动 Play 默认恢复 1 倍；回溯、转场及填写反馈期间不响应 I，暂停不会被倍速功能解除。合体慢动作相对当前倍速生效。

**手感调整**：点按左/右 Ctrl 开关 0.5 倍子弹时间，屏幕淡入/淡出轻微淡蓝色效果；关闭后恢复原先的正常/调试倍速，切换场景关闭子弹时间。分离时按下空格若已对齐，立即开始吸附；否则保留按住提示、松开再尝试的流程。默认横向吸附容差为 0.40 格。玩家或分离头部到达最高点或向上撞顶后，最初 0.10 秒下降使用 65% 重力；该缓冲支持回溯，并可在玩家配置中调整或关闭。

PageDown 或 HUD 的“下一关”跳过当前关，也可输入序号跳到指定关。跳过的关卡不会计为已通过。R 或“重开本关”刷新本关并返回入口，保留已通过记录。最后一关完成后保留拼接进度画面，可返回第一关重玩或返回选关。弹簧默认弹起高度统一为 4.5 格。

初始选关场景复用转场的编号拼图，保持各模块在大世界中的拼接位置。点击某一块即可进入；也可用左右方向键选择，Enter 进入。薄荷色表示已通过，青色表示可进入，灰色表示未解锁。首次开放序号最小的一关，通关自动解锁下一关；**P 解锁全部关卡**，只开放进入权限，不增加通关记录。游戏中按 **Esc** 或点击 HUD 的“返回选关”回到入口；全部关卡之间的推进仍在同一个游玩场景中进行。通关和解锁记录按大世界资源 ID 保存在本机 PlayerPrefs，退出后仍保留；编辑器的跳关会开放被访问的关卡，但不会记录为已通过。

**机关按钮三维模型**：`Assets/Prefabs/Interactables/Grid/GridMechanismSwitch.prefab` 已接入 `Button_Bottle.fbx` 底座与 `Button_Top.fbx` 顶盖及素材原有 URP 材质。可复用的纯视觉预制体位于 `Assets/Prefabs/Interactables/Models/Button3D.prefab`，宽、深各 1 格，高 0.22 格；视觉覆盖 Z=0～1，中心为 Z=0.5，原二维触发区域位于前侧边缘。踩下时顶盖沿局部 Y 轴下降 0.06 格（0.08 秒），松开后回弹（0.16 秒），底座保持固定；上下朝向、开关状态灯和回溯继续沿用原有机制。可在 `MechanismSwitch` 组件调整 `Pressed Cap Offset`、`Press Duration`、`Release Duration`。替换 FBX 后可使用菜单 `TapTap → 美术 → 配置 Button 按钮模型` 重新装配；现有关卡中的嵌套按钮自动继承更新。
