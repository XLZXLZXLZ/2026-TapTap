# 折线磁力连接试作

进入游戏后自动为已有玩家挂载 `MagneticLinkRemakeView`，替代旧磁力线的显示。无需修改场景或玩家预制体。旧脚本、特效资源和玩家逻辑保持原样；禁用玩家身上的新版组件即可恢复旧效果。删除本目录可彻底移除此试作。

新版采用五组三角折波（约十处转折）、圆角接缝、细亮芯与两层柔光，以及两个沿线运动的短光梭。折波持续从下半身向头部传播，线身叠加同方向移动的亮带，两端有小光晕并保持固定。吸附拉动时振幅收至 55%，仍保持流动，亮度增强，光梭改为向下半身流动。各层保持正常深度遮挡，不穿墙显示。

动画从现有模拟时钟读取时间，暂停时停止，回溯时沿历史时间反向播放。端点、阶段和时钟由适配器读取，纯绘制组件 `FoldedMagneticLink` 只接收世界坐标、显隐、张力、时间和尺度，不引用任何玩家类型。

辉光来自线条自身的叠加柔光层。特效不创建 Bloom Volume、不切换相机 HDR / 后处理 / Volume Layer Mask，也不改动 Pipeline Asset、Volume Profile 或滤镜资源，避免干扰已有自定义滤镜的输出流程。如果原有渲染配置已启用 Bloom，线条的 HDR 亮芯仍会自然参与其处理。

可在运行时调整：

- 玩家 → `MagneticLinkRemakeView`：Forward Offset（默认沿世界 Z 前移 0.08 个单位尺度）、Fade In Duration（默认 0.1 秒）、Fade Out Duration（默认 0.28 秒）。淡出时各层同步收细并平滑降低透明度，合体或断开时保留最后有效的连线跨度完成消散，避免端点重合导致突然关闭。
- 玩家子物体 `Folded Magnetic Link (Remake)` → `FoldedMagneticLink`：Core Width、Bend Width、Wave Count（折波数量）、Flow Speed（流动速度）、Irregularity（折点间距、摆幅和偏斜的不规则程度，默认 0.7）、HDR Core Color。不规则变化使用随模拟时间连续变化的噪声，保持流动和回溯连贯。

此试作在编辑器与打包版本中均自动启用，仅在游玩时生成。与仅供编辑器使用的区域线框彼此独立。未执行游戏运行测试或视觉验收。
