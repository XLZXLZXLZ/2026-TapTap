# 架子、齿轮、远景电线：透明贴图

仅含三类，共 8 张：2 张空架子、3 张齿轮、3 张远景电线。全部无文字、无数字、无背景底板。纯白 RGB + 抗锯齿 Alpha，可自由改颜色和透明度。

将 FactoryRackGearWireTextures 文件夹放入 Assets/ArtStyleTest，运行 Tools → Toy Factory → Import Rack Gear Wire Textures，然后将 Textures 中的 PNG 拖入场景。修改 SpriteRenderer → Color 调整颜色，A 控制透明度。工具通过自身路径定位文件，可放在 Assets 的其他子目录。

也可手动设 Texture Type 为 Sprite (2D and UI)，Sprite Mode 为 Single，并启用 Alpha Is Transparency。推荐远景电线使用比墙面略深的颜色，透明度约 0.2–0.5。用 Sorting Layer 和 Order in Layer 将装饰放在墙面上方、角色与机关下方。

这些都是二维平面贴图，不是立体模型。电线保留边缘留白，不是无缝平铺纹理；可缩放、翻转、错位叠放。贴在三维平墙上时需手动调整朝向，并与墙面稍微错开避免闪烁。

01–02：宽/窄空架；03–05：8/12/16 齿图标；06：横向下垂线束；07：纵向电线；08：沿墙布线。PNG 最长边 1024–2048。每个文件独立使用，无需切图。
