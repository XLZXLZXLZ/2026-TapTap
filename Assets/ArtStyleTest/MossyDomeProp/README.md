# 穹顶建筑 · 无植被版

打开 `Assets/ArtStyleTest/Scenes/Mossy_Dome_Prop_Study.unity`，Game 视图使用 **3:2**。
预制体：`Prefabs/Mossy_Dome_Shelter.prefab`，可以直接拖入其他场景。
预览：`Preview/Mossy_Dome_Prop_Study.png`，Unity / URP 实际相机渲染，1800×1200。

## 父子层级
场景中的 `Mossy_Dome_Shelter` 为完整建筑根节点，所有建筑部件和碎石都位于其下：

- `01_Dome_Shell`：外壳，按砌筑层 Course 和单独 ShellPanel 分组；另含放射状伸缩缝。
- `02_Main_Entrance`：主入口，细分外拱石块、内拱通道、深色内部空间、门槛和坡道。
- `03_Portholes`：左圆窗、右侧圆形通风口；各自包含分段石框、内套筒和深色凹口。
- `04_Service_Systems`：表面导线、独立管线、电箱；每个电箱包含外壳、盖板、标签和接线端。
- `05_Roof_Concrete_Stubs`：三个屋顶短柱，每个包含柱体、基座，局部带外露线。
- `07_Foundations_And_Rubble`：基础台、倾倒混凝土块和独立碎石。

相机、灯光与调色单独放在 `Studio_Presentation` 下，便于整组移动建筑和单独调整展示环境。

## 编辑方式
选择建筑根节点可整体移动、旋转或缩放；选择任意部件组可修改该部件，子物体会随父级一起变换。不同部件使用独立名称和材质。场景中建筑已连接到完整预制体；可通过 Unity 的 Prefab 编辑流程更新复用版本。

所有内容均为实际三维网格。参考图作为造型依据，未作为背景平面使用。圆窗和入口留有真实开口，后方设置深色凹入空间；内部仅搭建图中可见的通道与阴影空间。
