# 森林遗迹 · 精细美术研究场景

打开 `Assets/ArtStyleTest/Scenes/Forest_Ruins_Detailed_Study.unity`，Game 视图选择 **16:9**。
`Preview/Forest_Ruins_Detailed_Study.png` 是 Unity 2022.3.62f3c1 / URP 14 的实际 1920×1080 相机渲染。

## 建筑、地形与植被
- 石穹顶：八道交错砌筑层，每块石板具有厚度、不规则崩角与独立材质变化，另有细裂缝、浅色苔斑和环绕基座的碎石。
- 入口：六边形内凹门洞、倒角斜门柱、分块过梁、深色凹槽、赭色内框、双扇金属门、上下嵌板、铰链、铆钉、中缝和门槛。
- 遗迹：残断石柱、带倒角的倾倒石板、破损高架桥、桥墩柱帽、断裂栏板与外露钢筋，远处塔楼带破碎顶部、开放框架和残存楼板。
- 地形：连续起伏的谷地与右侧抬升的山坡；顶点色形成大块草地色彩变化，并留出弯曲的浅色行走痕迹。
- 植被：九组分布草簇与两组加密近景草簇、小型象牙色野花、不规则六层松树、暖棕色树干与折断枝条。

全部内容为可编辑三维几何，参考图未作为背景贴图。原有场景与共用项目渲染配置保持原样。

## 光照与气氛
- `Materials/Forest Sky.mat`：蓝色天空渐变与有起伏的程序化乳白云带。
- 主光：暖色方向光，俯角 39°、方位 42°、强度 1.5，柔和阴影；另有低强度冷色天空补光。
- 雾：蓝灰线性距离雾，36–210 米。草地专用着色器还叠加低处的轻微雾色近似。
- `Forest Atmosphere.asset`：ACES、曝光 +0.20、对比 -5、饱和 -2、白平衡、冷暖分离、轻 Bloom 和暗角。
- 景深：Bokeh，焦点 43 米、焦距 180 mm、光圈 f/1.6。可在全局 Volume 中关闭或调整。
- 灯光组内的 `Irregular off-camera canopy shadow` 是仅投影的画外树冠，用于形成参考图的暗色前景。

## 编辑与观察
Hierarchy 的 01–06 分组控制草地、穹顶、森林、城市远景、灯光与后处理。
Play 模式：WASD 移动，Q/E 升降，右键转向，Shift 加速，R 恢复参考视角。

菜单 `Tools > Art Style Test > Create Detailed Forest Ruins Study` 为可复现生成入口，已有场景时拒绝覆盖；查看成果直接打开现有 scene 即可。
